# Report

Draft the technical report in a shared doc (e.g. Google Docs) so all 15 members
can edit simultaneously. Follow the structure in Section 11 of the project brief:

1. Cover page (title, team members, local Ghana context, chosen organisation/problem)
2. Problem statement, assumptions, input-output definitions, system boundaries
3. Dataset description, data dictionary, database schema
4. System architecture and module design
5. Data-structure implementation (diagrams + explanations)
6. Algorithm implementation (pseudocode + selected Java snippets)
7. Correctness evidence (trace tables, invariants, proof sketches, edge-case tests)
8. Performance analysis (method, input sizes, raw results tables, graphs, interpretation)
9. Database integration evidence (schema, sample records, screenshots, run logs)
10. Responsible algorithm selection (when appropriate / when not)
11. Individual contribution statement + oral-defense prep notes
12. References and appendices

Export the final version to both PDF and DOCX before submission.
